# Contributing Guide

## Flow

1. Create or pick a scoped issue.
2. Create one branch for the change.
3. Keep implementation focused.
4. Run tests and lint locally.
5. Update documentation when behavior or runtime configuration changes.

## Checks

```bash
pytest
ruff check .
```

## Pull Request Content

- Summary
- Linked issue
- What changed
- How to test
- Compatibility impact
